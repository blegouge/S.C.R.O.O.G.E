# Security Policy

## Supported Versions

Only the latest release of S.C.R.O.O.G.E is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not report it publicly. Instead, report it directly to the maintainer via email or via a private vulnerability disclosure on GitHub.

We will acknowledge receipt of your report within 48 hours and work with you to address and resolve the issue.
